- iPhone/Mac: WOFF2 и переменные шрифты поддерживаются Safari; `-webkit-text-size-adjust: 100%`,
  `text-wrap: balance` — прогрессивное улучшение (старые Safari просто переносят обычно).
- Можно улучшить: предзагрузка (`preload`) кириллицы Cormorant 400 и 400 italic — ими набрано
  название на обложке; без неё на медленной сети название на мгновение показывается системным шрифтом.

## 4. Мобильная версия (320 и 375 px, все 17 страниц)

- Горизонтальной прокрутки нет нигде; текста мельче 12 px нет; у всех изображений есть `alt`;
  у всех кнопок есть подписи. Меню, просмотр фото, нижняя панель связи работают.
- **Малые области нажатия (18–23 px по высоте)** у самостоятельных ссылок: хлебные крошки,
  телефоны и почта в блоке контактов, «Маршрут в Яндекс/Google Картах». Норма WCAG 2.2 — не меньше
  24 px, для телефона лучше 44 px. Особенно важно для номеров телефонов.
- **iPhone в горизонтальной ориентации:** в `<meta viewport>` стоит `viewport-fit=cover`, но у шапки,
  меню и боковых полей нет отступов `safe-area-inset-left/right` — логотип и кнопки могут уйти под «чёлку».
- **Карта на телефоне** появляется через несколько секунд после прокрутки до контактов:
  сначала грузится 1,6 МБ (≈ 435 КБ в gzip) скриптов MapLibre.

## 6. CMS

Редактируется: контакты (адрес, координаты, часы, телефоны, почта, оплата, рассрочка), все 108 позиций
каталога и тексты 9 разделов, фото разделов, тексты главной (обложка, преимущества, цитата, материал,
ателье, этапы), страницы «Услуги», «Выезд дизайнера», «Ткани», «Лифт-системы», «Блэкаут», «Наши работы»
(вступление и сами работы с фото), SEO-тексты подборок.

Не реализовано / нельзя из CMS:
- вход через GitHub — нужен репозиторий и бесплатный OAuth-воркер (после публикации);
- видео обложки, пункты меню и текст подвала;
- создание и удаление разделов каталога — заблокировано намеренно (адреса страниц);
- предпросмотр в стиле сайта внутри CMS (CMS показывает поля, не вёрстку).

Безопасность: вход только через GitHub OAuth (`auth_methods: [oauth]`), токенов в настройках и в
репозитории нет (проверено поиском), секрет OAuth хранится только в воркере, `/admin/` закрыт от
индексации. Рекомендуется: двухфакторная защита GitHub; заголовки безопасности на хостинге
(CSP, `X-Frame-Options` для `/admin/`); периодически обновлять Sveltia (версия зафиксирована).

## 7. Перед публикацией

- **Персональные данные:** форм, аналитики, cookie и сбора данных нет. Сторонние запросы —
  только `images.unsplash.com` (временные фото) и `tiles.openfreemap.org` (карта): эти сервисы видят
  IP-адрес посетителя. После переноса фото на свой сервер останется только карта. Стоит решить, нужна
  ли короткая страница «Политика конфиденциальности» с упоминанием карты.
- **Доступность:** контраст текста проверен (≥ 4,5:1), есть «Перейти к содержимому», видимый фокус,
  управление с клавиатуры в меню и просмотре фото, учёт «Уменьшить движение». Замечания — п. 4.
- **Лицензии:** фото — п. 3; шрифты — OFL; MapLibre — BSD-3; Sveltia — MIT; данные карты — ODbL с
  обязательной подписью (выводится). Логотип — подтвердить права у владельца.
