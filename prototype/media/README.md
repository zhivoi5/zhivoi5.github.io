# Медиа для прототипа «Выпуск»

Положите файл с точным именем из таблицы в эту папку — прототип сразу начнёт его использовать.
Пока файла нет, сервер прототипа (`serve.mjs`) подставляет временную стоковую заглушку.
Подписей об источнике в интерфейсе нет и не будет.

## Общие требования

- JPEG, качество 85, sRGB, длинная сторона не меньше указанной.
- Без людей с лицами, без текста, логотипов и узнаваемых брендов.
- Единый свет и палитра: тёплый молочный, шампань, глубокий изумруд, дуб, латунь.
- Перед заменой проверьте: прямые вертикали окон, карниз реально держит ткань, нет «пластиковой» кожи ткани и лишних складок.

**Общий хвост для каждого промпта:**
```
photorealistic editorial interior photograph, premium residential apartment, soft natural
daylight, gentle realistic shadows, shot on full-frame camera with 35mm lens at f/5.6,
straight verticals, true-to-life fabric weight and weave, subtle film grain, muted warm
palette of milky white, champagne and deep emerald, no people, no text, no logos
```

**Негативный промпт:**
```
cgi, 3d render look, plastic texture, oversaturated, HDR halo, warped window frames,
floating curtains, curtain without rod or track, melted objects, extra furniture legs,
text, watermark, logo, fisheye
```

## Видео «живые шторы»

**Способ:** image-to-video от готового кадра `hero-poster.jpg`, затем склейка в бесшовную петлю.

1. Сгенерировать постер (см. таблицу) и утвердить его как кадр.
2. Подать его в модель image-to-video (Veo, Kling, Runway Gen-4, Luma) с промптом:
   ```
   locked-off static camera, no camera movement, the emerald velvet curtains sway very
   gently as if from a faint draft, folds slowly shift and settle, sheer tulle behind
   barely moves, lighting and room stay perfectly still, realistic fabric physics,
   slow and subtle motion, 24 fps
   ```
   Негатив: `camera pan, zoom, flicker, lighting change, morphing objects, fast motion`.
3. Если стены или окно «плывут» — оставить движение только на шторах: маска по портьерам,
   остальное — неподвижный кадр постера (приём синемаграфа).
4. Петля: последние ~1 с плавно смешать с первыми (кроссфейд) — шва не видно.
   Для ткани также подходит «туда-обратно» (вперёд + реверс).
5. Кодирование, без звука, 24 к/с, 6–8 с:
   - `hero-loop.webm` — VP9, 1920×1080, ≈ 2–3 МБ;
   - `hero-loop.mp4` — H.264 High, 1920×1080, `+faststart`, ≈ 3–4 МБ.

На телефонах, при «Уменьшить движение» и в режиме экономии трафика видео не загружается —
показывается постер. Над видео есть кнопка «Пауза».
